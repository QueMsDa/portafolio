Proyectos en línea

Aplicaciones web full-stack desarrolladas con Next.js, TypeScript, SQL y Redis, desplegadas en Vercel. Desde calculadoras hasta apps con base de datos, almacenamiento en la nube y servicios en tiempo real.

Proyecto 1 · JavaScript

Calculadora de Promedio

Herramienta web para el cálculo de promedio ponderado de notas académicas. Permite ingresar calificaciones con distintos pesos y obtener el promedio final de forma inmediata. Desarrollada con HTML, CSS y JavaScript puro.

Proyecto 2 · JavaScript

Convertidor de Temperatura

Aplicación web para convertir entre unidades de temperatura: Celsius, Fahrenheit y Kelvin. Interfaz limpia y cálculo instantáneo. Útil para ejercicios de termodinámica y balance de energía en ingeniería ambiental.

Abrir en Vercel
Proyecto 3 · Next.js · TypeScript · SQL

Mi Closet — Closet Virtual

App web full-stack para gestionar un armario virtual. Subí fotos de tu ropa, filtrá por categoría, marcá favoritos, registrá cuántas veces usaste cada prenda y armá outfits combinando prendas. Usa Vercel Postgres (SQL) para los datos y Vercel Blob para las imágenes.

Abrir en Vercel Ver en GitHub
Proyecto 4 · Next.js · TypeScript · Redis

MusicHome — Música en Google Home

App web + servicio Windows para subir música personal a la nube y transmitirla a un Google Home sin necesitar Spotify. Lee metadatos ID3 automáticamente, controla el volumen en tiempo real y persiste la cola entre reinicios. Integración con IFTTT para comandos de voz.

Abrir en Vercel Ver en GitHub
